# 옆자리 (Yeopjari) — 안내에서 코칭까지, 음성 운전 코치

**한 줄 소개:** 내비는 ‘어디로’를 말하고, 옆자리는 ‘어떻게’를 말한 뒤 운전자가 실제로 했는지 차량 신호로 확인해 코칭하는 Pleos Connect 차량용 앱입니다.

- 2026 현대자동차그룹 차량용 앱 개발 공모전 출품작 (개인 참가)
- 차량을 제어하지 않는 **읽기 전용** 앱입니다. 모든 안내는 참고용이며 최종 판단과 책임은 운전자에게 있습니다.

## 시연 영상
- 요약본(약 6분): [`video/yeopjari_demo_summary.mp4`](video/yeopjari_demo_summary.mp4)

## 실행 방법
1. **Pleos Connect 에뮬레이터(Android Automotive API 34)** 또는 실제 차량에 APK를 설치하고 실행합니다.
2. 처음 실행하면 옆자리 소개가 나옵니다. **시작할게요**를 누릅니다.
3. 출발 화면의 **시연 주행 A~D**를 누르면 실제 주행 없이 코칭 흐름을 재생합니다(시연 모드 기본 켜짐).
   - A. 첫 고속도로 합류 — 왼쪽 합류, 뒤차 경고, 3차로 사고, 터널 전조등
   - B. 우회전과 급제동 — 연료 부족, 반대쪽 깜빡이 즉시 경고, 급제동 기록, 깜빡이 끄기
   - C. 같은 길 다시 — 어린이보호구역, 지난 급제동 지점 기억, 연속 회전, 도착
   - D. 고속도로 출구 — 1차로·버스전용차로·느린 주행, 출구 3km/1km/500m, 뒤차 경고
   - E. 강사 모드·질문·길 놓침 — 틈새 요령, 말로 질문하면 대답, 회전 안내가 오면 끊고 이어 말하기, 길을 놓쳤을 때 침착하게
4. 실제 주행: 설정에서 **시연 모드**를 끄면 차량 신호(Vehicle SDK)와 내비(NaviHelper SDK)로 동작합니다.
5. 일반 안드로이드 휴대폰에서도 시연 모드로 실행됩니다(차량 화면 1280×720 기준으로 축소 표시).

## 테스트 환경과 필요한 설정
| 항목 | 내용 |
|---|---|
| 확인한 환경 | Pleos Connect Emulator v2.1.0 (Android 14, API 34), Samsung Galaxy S23 Ultra (시연 모드) |
| 권한 | 차량 신호(방향지시등·브레이크·기어·연비·계기판 표시등·안전벨트·와이퍼), 내비 경로, 차량 속도, 위치, 마이크('말로 다시 듣기'), Pleos 음성(TTS·STT) |
| 음성 | 차량: Pleos TextToSpeech / SpeechToText (기기 안 방식, 인증 키 불필요, 차량의 Pleos 음성 서비스 필요). 휴대폰: 안드로이드 기본 음성·음성 인식 |
| 마이크 | '말로 다시 듣기'는 안내가 끝난 뒤 5초만 듣고 소리를 저장하지 않습니다. 설정에서 끌 수 있습니다 |

## 핵심 기능
- **안내 → 확인 → 코칭:** 회전·합류·출구 전 단계별 미리 알림 → 깜빡이 확인(법정 기준보다 앞에서) → 칭찬 또는 다음 연습 포인트
- **실력에 맞춰 줄어드는 안내:** 처음엔 순서까지 자세히, 잘할수록 짧게. 여러 번 들은 원칙은 생략
- **후측방 경고 연동, 실시간 사고·공사·정체, 주의 구간, 고속도로 흐름(1차로·버스전용차로·느린 주행)**
- **어르신·초보자 배려:** 천천히 말하기, 중요한 안내 앞 알림음, ‘깜빡이’·‘잠시 뒤’ 같은 쉬운 말, 말로 다시 듣기, 페달 오조작 의심 경고, 밤·비 안내, 1시간 휴식
- **동승 강사(강사 모드·질문하기·목소리 선택):** 말 많기 3단계(조용히/보통/강사 모드), 조용한 구간에 운전 요령, 자주 묻는 질문 30여 개에 대답, 급한 안내가 오면 "잠깐만요!" 하고 끊었다가 이어서 말하기, 여자·남자 목소리
- **주행 후 리포트:** 잘한 점 하나·다음에 해 볼 것 하나(+이유), 실력 변화, 옆자리 미션·포인트(미션 1개 1P, 하루 최대 100P, 차 화면 광고 없음), 결과 공유(직접 누를 때만, 위치 제외), 주차 위치 기억

## 구조
| 폴더 | 역할 |
|---|---|
| `model` | 차량·내비 상태, 설정, 운전자 실력 |
| `source` | 신호 출처 — `RealSource`(Vehicle·NaviHelper SDK) / `ReplaySource`(시연 시나리오) |
| `coach` | 코칭 규칙 엔진(`CoachEngine`, 안드로이드 비의존), 문구(`Phrases`), 음성 출력(`Speaker`, Pleos/기본 음성), 말로 다시 듣기(`RepeatListener`) |
| `trip` | 주행 기록·리포트, 기기 내 저장 |
| `ui` | 소개 / 출발 전 / 주행 중 / 주행 후 / 설정 화면 (Jetpack Compose) |

## 빌드와 테스트
```
./gradlew testDebugUnitTest   # 코칭 엔진 자동 테스트 30개
./gradlew assembleRelease     # release APK (서명 정보는 signing/keystore.properties, 저장소에 포함하지 않음)
```
